# 1.21.0 Full Dictionary Option

## Summary

Add a settings cog between the help (`?`) button and theme button. The settings
panel includes a two-way dictionary size selector with explanatory copy
warning that the app must load the selected dictionary into the browser, so
larger modes take longer and use more memory. The setting persists in
`localStorage` and applies after reload.

Use bundled English lookup artifacts, not raw upstream JMdict. "Full" means
all English JMdict senses/glosses are included in the app's existing
lookup-friendly shape; it does not include all-language JMdict or raw source
metadata. "Ultra-compact" means entries marked common by JMdict priority data,
plus grammar-related entries used for particle/auxiliary disambiguation.

## Key Changes

- Add `dict/jmdict-ultra-compact.json.gz` and `dict/jmdict-full.json.gz`,
  generated from the same `jmdict-eng-*.json.zip` source.
- Extend `scripts/compact_jmdict.py` so it builds:
  - `jmdict-ultra-compact.json.gz`: common JMdict entries and grammar-related
    entries, all English senses plus grammar disambiguation fields.
  - `jmdict-full.json.gz`: same runtime object shape, but `g` includes every
    English sense/gloss group for each retained JMdict entry.
- Keep lookup/rendering logic compatible with both artifacts:
  - `lookupWord` continues reading `entry.g`.
  - `lookupParticle` continues using `pg`/`pg2`.
  - Full mode may show longer English definitions because more sense groups are
    present.
- Add settings UI in the header:
  - Cog icon button between help and theme.
  - Small popover/dialog anchored from the cog.
  - Radio options: "Ultra-compact" and "Full".
  - Explanation: larger dictionaries load more data into this one-page app, may
    start slower, and are not recommended for devices with limited memory
    because browsers may evict and reload the tab.
- Persist the setting under `dictionaryMode`.
  - Migration: any existing `dictionaryMode="compact"` value is migrated to
    `dictionaryMode="full"` and the old value is removed from localStorage.
- Apply setting after reload:
  - Choosing a mode stores the preference.
  - Show concise text/button in the settings panel indicating reload is needed.
  - On next startup, `loadJMdict()` fetches the selected mode:
    `dict/jmdict-ultra-compact.json.gz?v=21`,
    `dict/jmdict-full.json.gz?v=21`.
- Update docs to describe ultra-compact vs full English dictionary mode and current
  approximate sizes.

## User-Facing Behavior

- Full mode is the default.
- Ultra-compact mode is opt-in.
- If the selected dictionary fails to load, existing retry behavior and final
  load error handling remain unchanged.
- If a user toggles the checkbox while reading, the current session keeps using
  the already-loaded dictionary until reload.
- Settings panel can be closed by clicking the cog again, clicking outside, or
  pressing Escape.

## Assumptions

- "Full JMdict" means full English JMdict content, not multilingual JMdict.
- Full mode should use all English senses while preserving the app's current
  simple display model.
- Ultra-compact mode may miss lookups because JMdict commonness is a rough
  priority signal.
- The setting applies after reload, not by hot-swapping dictionaries
  mid-session.
- Exact compressed/uncompressed sizes will be measured after generation and
  recorded in docs.
